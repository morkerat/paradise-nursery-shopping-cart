# Paradise Nursery - Shopping Application

Welcome to **Paradise Nursery**, an interactive and user-friendly e-commerce web application for plant enthusiasts! Browse a variety of houseplants, manage your shopping cart dynamically, and experience seamless front-end shopping.

## Features
- **Landing Page:** Elegant introduction with company history and quick start button.
- **Product Listing Page:** Plant catalog grouped into 3 distinct categories with 18 unique houseplants.
- **Redux Shopping Cart:** Full state management to add, remove, increment, and decrement items dynamically.
- **Interactive Header:** Dynamic cart icon counter tracking total item quantity across pages.

## Tech Stack
- React.js
- Redux Toolkit
- CSS3
